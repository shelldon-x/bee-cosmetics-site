# Bee Cosmetics — Plataforma Web & Catálogo Digital

Plataforma Web da **Bee Cosmetics**, desenvolvida para apresentar a marca, organizar seu catálogo de produtos e conectar consumidores aos principais canais de venda.

Este repositório representa um produto digital real que integra **requisitos, desenvolvimento front-end, validação funcional, SEO técnico, dados estruturados, versionamento e deploy**.

🌐 **Produção:** https://beecosmetics.store

---

## 🎯 Sobre o projeto

A plataforma foi estruturada como uma vitrine digital para a **Bee Cosmetics**, marca de produtos capilares voltada especialmente para cabelos ondulados, cacheados e crespos.

O objetivo é reunir em uma única experiência digital:

- apresentação institucional da marca;
- catálogo da linha de produtos;
- informações e diferenciais de cada produto;
- conteúdo para auxiliar a escolha e utilização da linha;
- direcionamento para canais de compra;
- integração com marketplaces;
- experiência responsiva em diferentes dispositivos.

O projeto combina conhecimentos de **produto, requisitos, desenvolvimento Web, qualidade e experiência do usuário**.

## 🧪 Qualidade e validação

O projeto utiliza validações durante seu processo de desenvolvimento e evolução.

O objetivo é garantir que alterações de conteúdo, interface e integrações não comprometam os principais fluxos da plataforma.

### Validação funcional

Entre os elementos verificados estão:

- navegação;
- menus;
- catálogo;
- apresentação dos produtos;
- CTAs;
- links internos;
- links externos;
- direcionamento para canais de venda;
- comportamento dos componentes da interface.

### Validação responsiva

A interface é verificada em diferentes tamanhos de tela, considerando aspectos como:

- organização do conteúdo;
- navegação;
- cards de produtos;
- imagens;
- textos;
- botões;
- CTAs;
- comportamento dos componentes;
- experiência em dispositivos móveis.

### Validação de conteúdo

Como a plataforma apresenta informações comerciais e de produto, também são verificadas:

- consistência das informações;
- nomes dos produtos;
- organização do catálogo;
- links de compra;
- apresentação visual;
- metadata relacionada ao conteúdo.

### Regressão e retestes

Após alterações relevantes, os principais elementos da plataforma são novamente validados para identificar possíveis impactos em funcionalidades existentes.

O fluxo pode ser representado de forma simplificada como:

```text
Requisito
   ↓
Implementação
   ↓
Validação
   ↓
Identificação de inconsistências
   ↓
Correção
   ↓
Reteste
   ↓
Publicação
```

## 📁 Estrutura do projeto

O projeto utiliza uma arquitetura Web estática organizada em arquivos de aplicação, configuração e recursos visuais.

```text
bee-cosmetics-site/
│
├── index.html
├── robots.txt
├── sitemap.xml
├── site.webmanifest
├── vercel.json
│
├── logos/
├── products/
├── results/
├── icons/
└── og/
```

### Principais diretórios

- `logos/` — recursos relacionados à identidade visual da marca;
- `products/` — imagens e recursos relacionados aos produtos;
- `results/` — materiais visuais relacionados a resultados;
- `icons/` — favicons e demais ícones;
- `og/` — imagens utilizadas para compartilhamento e Open Graph.
